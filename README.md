## О проекте

Movo превращает домашние двигательные упражнения в короткие игровые занятия. Ребёнок встаёт перед камерой, смотрит демонстрацию Мово, повторяет движение и сразу получает понятную обратную связь.

Приложение работает в браузере. Камера используется как игровой контроллер, а распознавание позы выполняется на устройстве пользователя.

Первый курс помогает различать левую и правую стороны. Следующие занятия развивают равновесие, координацию и двигательную память.

**Направление кейса:** B / FITNESS — фитнес-тренер. Приложение контролирует выполнение двигательных упражнений, помогает исправлять технику и показывает результат занятия.

**Рабочая версия:** [movo-app-roan.vercel.app](https://movo-app-roan.vercel.app)

## Описание проекта для сдачи

**Что создано:** Movo — браузерная игровая платформа двигательных упражнений для детей. Ребёнок повторяет движения персонажа перед обычной веб-камерой, получает обратную связь и проходит короткие уроки с итоговым результатом.

**Выбранное направление:** B / FITNESS — фитнес-тренер.

**Какие движения распознаются:**

- поднятие левой руки;
- поднятие правой руки;
- поднятие двух рук;
- разведение рук в стороны;
- стойка на правой и левой ноге;
- сочетание поднятой руки со стойкой на одной ноге;
- выполнение движений в заданной последовательности.

**Как реализован режим «ошибка»:** MediaPipe определяет координаты ключевых точек тела, после чего собственная логика Movo проверяет сторону, высоту рук, положение локтей, опорную ногу, устойчивость и порядок движений. Если упражнение выполнено неточно, ребёнок получает конкретную текстовую и голосовую подсказку: например, «Подними руку выше», «Опусти другую руку», «Держи руки ровнее» или «Подними ногу чуть выше». После исправления движение засчитывается.

## Режим «ошибка»

Movo проверяет не только факт распознавания позы, но и конкретную причину неточного выполнения. Для этого ключевые точки MediaPipe проходят через собственные правила проекта в `src/pose.js`.

Система сравнивает положение запястий, локтей, плеч, бёдер, коленей и ступней. Пороговые значения рассчитываются относительно высоты корпуса ребёнка, поэтому проверка меньше зависит от роста и расстояния до камеры.

Примеры обратной связи:

| Ошибка | Подсказка |
|---|---|
| Поднята другая рука | «Это правая рука, а нужна левая» |
| Рука находится слишком низко | «Подними руку выше» |
| Подняты две руки вместо одной | «Опусти другую руку» |
| Руки в позе самолёта согнуты | «Держи руки ровнее» |
| Нога поднята недостаточно высоко | «Подними ногу чуть выше» |
| Ребёнок сильно двигается в позе баланса | «Старайся не шататься» |
| Тело не помещается в кадр | «Я тебя не вижу целиком. Отойди чуть дальше» |

Подсказка показывается на экране и озвучивается. После исправления движение засчитывается, а ребёнок переходит к следующему заданию.

## Собственная логика проекта

MediaPipe используется для получения координат тела. Решение о результате принимает логика Movo:

- определяет, какая сторона тела активна;
- проверяет высоту и положение рук;
- замечает одновременно поднятую лишнюю руку;
- оценивает положение рук относительно плеч;
- определяет поднятую и опорную ногу;
- отслеживает раскачивание во время баланса;
- проверяет удержание позы в течение заданного времени;
- управляет порядком движений и выбором следующей подсказки.

## Утренняя зарядка

На главном экране находится отдельное ежедневное занятие примерно на четыре минуты.

В зарядку входят:

1. Потягивание с двумя поднятыми руками.
2. Подъём левой руки.
3. Подъём правой руки.
4. Поза «Самолёт».
5. Стойка на одной ноге.
6. Короткая последовательность из трёх движений.

За первое выполнение в течение дня ребёнок получает 20 звёзд. Зарядку можно повторять без дополнительной награды.

## Как проходит урок

1. Мово объясняет задание и показывает движение.
2. Ребёнок разрешает доступ к камере и встаёт в рамку.
3. Приложение находит ключевые точки тела.
4. Ребёнок повторяет показанное движение.
5. Система проверяет сторону, высоту рук и положение тела.
6. При ошибке Мово даёт короткую голосовую и визуальную подсказку.
7. После выполнения показываются время, количество движений и награда.

## Запуск проекта

### Требования

- актуальная LTS-версия Node.js;
- npm;
- современный браузер;
- веб-камера для автоматической проверки движений.

### Установка

```bash
git clone https://github.com/dardau/movo_app.git
cd movo_app
npm install
```

### Режим разработки

```bash
npm run dev
```

После запуска откройте адрес, который Vite покажет в терминале. Обычно это `http://localhost:5173`.

### Production-сборка

```bash
npm run build
npm run preview
```

Готовые файлы появятся в папке `dist`.

## Доступ к камере

Для работы распознавания браузеру нужно разрешение на использование камеры. В production камера доступна только на HTTPS-сайте или на `localhost`.

Видеопоток:

- обрабатывается локально в браузере;
- не отправляется на сервер;
- не записывается приложением;
- останавливается после выхода из урока.

При первом запуске распознавания может понадобиться интернет для загрузки модели и WebAssembly-файлов MediaPipe.

## Хранение прогресса

Прогресс сохраняется в браузере под ключом:

```text
movo.progress.v1
```

В нём хранятся завершённые уроки, звёзды, серия занятий и количество выполненных заданий за день. После очистки данных браузера локальный прогресс будет удалён.

## Ограничения MVP

- прогресс хранится только в текущем браузере;
- профили родителей и специалистов пока не синхронизируются между устройствами;
- качество распознавания зависит от освещения, расстояния до камеры и видимости тела;
- приложение показывает игровые результаты упражнений и не ставит медицинские диагнозы.
