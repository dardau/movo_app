# Magic Motion Academy

Игровая браузерная платформа двигательных упражнений для детей. Первый курс — «Лево и право»: ребёнок проходит короткие занятия по учебной дорожке, собирает звёзды и открывает следующие факультеты академии.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка: `npm run build`.

MVP включает карту курса, факультеты, задания, награды, урок с камерой браузера и демо-режимом, экран результата и родительский уголок. Видеопоток камеры не отправляется на сервер. Распознавание поз и автоматическая классификация движений пока не подключены.
