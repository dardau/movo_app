# Movo

Игровая браузерная платформа двигательных упражнений для детей. Первый курс — «Лево и право»: ребёнок проходит короткие занятия по учебной дорожке, собирает звёзды и открывает следующие факультеты академии.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## MVP

- карта курса и прогресс по урокам;
- факультеты, ежедневные задания и награды;
- короткий интерактивный урок с камерой браузера и демо-режимом;
- экран результата;
- родительский уголок с недельной сводкой.

Видеопоток камеры не уходит с устройства. Поза считается в браузере через MediaPipe Pose Landmarker: левая рука, правая рука и обе руки. Если жест неточный, Мово говорит, что именно исправить. Прогресс факультетов и заданий хранится в `localStorage` (`movo.progress.v1`), без сервера и базы данных.

Для распознавания нужны интернет при первом запуске (модель и wasm MediaPipe) и разрешение камеры. Если камеры нет, урок можно пройти кнопкой «Я готов(а)!».
